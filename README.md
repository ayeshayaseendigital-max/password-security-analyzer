
# 🔐 Password Security Analyzer

## About the Project
Password Security Analyzer is a beginner-friendly Python project built with Streamlit. It helps users understand basic password security by checking passwords against different security criteria.

## Features
- Password strength checking
- Secure password generation
- Custom password length selection
- Copy generated password option
- Password strength score
- Visual strength progress bar
- Security checklist
- Password improvement recommendations
- Common password detection
- Password security tips

## Technologies Used
- Python
- Streamlit
- Secrets Module
- String Module

## Project Structure
password security analyzer project/
- app.py
- password_checker.py
- requirements.txt
- README.md

## How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required packages:

```bash
pip install -r requirements.txt
```

5. Run the application:

```bash
python -m streamlit run app.py
```

6. Open the local URL shown in the terminal.

## Project Purpose
The purpose of this project is to learn Python programming and explore basic cybersecurity concepts, especially password security.

## Disclaimer
This is an educational project. It uses a basic checklist and is not a professional password security assessment tool. Do not enter real account passwords.
